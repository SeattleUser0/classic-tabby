              01 · What Classic Tabby is
              

              Classic Tabby is a performance MIDI sequencer firmware for the M-VAVE SMK-37 Pro. It is a fork of SMK37 Open V01. It plays songs made of rows and blocks, keeps the exact timing of imported MIDI files, changes scenes on the bar, launches patterns per track, and sends program changes and control changes to the gear on each MIDI channel.
              

              What it does
              

                

              • Plays up to 16 songs from the device. A song has up to 128 rows. Each row gives every one of the 8 tracks one block of up to 64 steps, with up to 4 notes per step.
                • 

              • Keeps note starts and lengths to 1/480 of a 16th step, so a nudged kick stays nudged.
                • 

              • Queues a jump to any row from the pads. The jump lands on the next bar or at the end of the row.
                • 

              • Launches any pattern of a track on its own loop, on the next bar, while the other tracks keep following the song.
                • 

              • Sends program changes, bank selects and control changes when a row starts, with the gaps your gear needs and a lead before the bar.
                • 

              • Is the clock master. It sends MIDI Clock, Start, Stop and Song Position Pointer to the gear on the cable.
                • 

              

              What it does not do
              

                

              • No sampler. The SAMPLER sound source cannot be chosen. A project that had a sampler track loads with the 808 kit on that track.
                • 

              • No DX7 operator editing on the device. The DX7 quick page stays (preset, bank, ALGORITHM, FEEDBACK, TRANSPOSE, LEVEL). Voices are edited and imported in the workbench. Pressing EDIT on another sound source, or SCL, ENV or SHIFT+ENV outside the song pages, shows VOICE EDIT MOVED TO WORKBENCH.
                • 

              • No Bluetooth page and no project NAME page on the device. Both moved to the workbench.
                • 

              • No factory scenes. The HOME list shows the 16 USER project slots only.
                • 

              • No external clock in song mode. A song runs from the internal clock. With the clock set to MIDI the SONG page refuses to start and shows SONG NEEDS INTERNAL CLOCK.
                • 

              

              The built-in synth is a preview
              

              The SMK-37 keeps five sound sources: DX7 FM (called FM6 in the documentation), BASS 303, DRUM 808, PSG and PLUCK. In a song they are there to audition a part before it goes to external gear, or to play a part when no gear is on that channel. Which tracks sound inside and which go out is set per track with the SEQ setting on the MIDI TRACK page. Chapter 09 explains it.
              

              Where to see the installed version
              

                

              • Boot screen: the line under OFFICIAL OPEN shows the version, for example TABBY-V03.1. The screen font has capitals only.
                • 

              • Workbench: the badge next to the title shows the same version.
                • 

              • Device update tab: the Version line shows it. Firmware details also show the build ID and the Open base version, which stays V01.
                • 

              

              

              02 · Getting started
              

              Back up first
              

              Before you install, keep what you want to keep. In Projects & sounds, under Device projects, load each slot you care about and click Back up current project. Under Song mode, read each song and click Export .tabby. Songs are the one thing a factory V16 restore overwrites in part, so keep the .tabby files.
              

              Install
              

                

              1. Open the Classic Tabby workbench in desktop Chrome or Edge. Use the hosted page or the SMK37-Open-Source.html file from the release.
                2. 

              2. Open the Device update tab. The page shows Firmware SMK37 Pro Open and the version. Check that the version is the one you downloaded.
                3. 

              3. Connect the SMK-37 Pro by USB. Tick the back-up box. Click Connect device and allow MIDI with SysEx.
                4. 

              4. Read the identity line. SMK-37 Pro_8000001 is an Open firmware. SMK-37 Pro_016 is the factory firmware. Anything else is not this device, so stop.
                5. 

              5. From an Open firmware, click Start update. From the factory firmware, open Migration, factory restore and forced updates, tick Force flash, wait for the page to reconnect, confirm the warning, then Start update. If the device does not answer, power-cycle it and connect again; never use force flash on an Open firmware.
                6. 

              6. Keep power and USB connected until the page reports the restart and the version check.
                7. 

              

              Songs written by tabby-v02.0 keep playing as before, including swing. Reflashing from tabby-v03.0 to tabby-v03.1 is optional. Both have the same sequencer.
              

              First boot
              

              The boot screen shows SMK37, OFFICIAL OPEN and the version. When song storage holds data that is not in the song format (V01's sample bank or DX7 library, or what the tabby-v04.0 storage move left), the device shows OLD DATA IN SONG STORAGE - SEE ACTIONS for six seconds. Until it is erased, the SONG page says OLD DATA IN SONG STORAGE and no song can be written or played. The workbench says the same when it connects the project library.
              

              To erase it: hold SEQ for about 0.6 s to open the ACTIONS menu, turn K5 or K1 to ERASE OLD DATA and press the 4th button in the left group (after SHIFT, FADER BANK, HOME); the screen asks ERASE OLD DATA? and a second the 4th button in the left group (after SHIFT, FADER BANK, HOME) confirms (HOME cancels). The workbench's Erase old data… does the same after its own confirmation. The erase runs one sector per control cycle and dips the audio briefly if something plays. Projects, tunings and settings are not touched. Afterwards the SONG page says NO SONG HERE - UPLOAD FROM THE WEB WORKBENCH and the storage status reports 326080 bytes free.
              


              Connect the workbench
              

              Open Projects & sounds and click Connect project library. The page reads the device's capabilities. The Song mode group becomes usable with the device as the target, and the Bluetooth settings group appears. Everything in this tab talks to the device over USB MIDI. Close other MIDI software first if the connection fails.
              

              The Play & edit tab has shortcuts into the simulator's pages. Song mode opens the SONG page and Track launch opens the TRACK LAUNCH page in the browser simulator, which runs the same firmware code.
              

              

              03 · Songs
              

              Rows, blocks, repeats, step lengths
              

              A song is a list of rows. A row names one block per track, eight ids in all. A block is a pattern of up to 64 steps with up to 4 notes per step. Block id 0 means the track is silent in that row. One block can appear in many rows and on many tracks, so a drum pattern used in 20 rows is stored once.
              

              Each row also has a repeat count from 1 to 64, a step length of 16, 32, 48 or 64 steps, and a Loop here flag. A row of 16 steps is one bar. The song plays the row's blocks for the row's length, then plays the row again for each repeat, then moves to the next row. A row with Loop here repeats until you jump away.
              

              The song header holds the name (12 characters), a tempo override (0 keeps the project tempo), the Loop the song flag with its Loop start row, the jump landing rule (next bar or end of row), the swing flag, and an output channel per track (0 keeps the device OUT CH of that track).
              

              What a song stores and what the project slot stores
              

              The song stores notes, rows, row events, output channels and the tempo override. The project stores sounds, mixer levels, swing, the clock source and the per-track MIDI settings (IN CH, OUT CH, SEQ, OUT PORT). A song plays with whatever project is loaded on the device. The song's project slot field is only a note of the project it was made for. The device does not load that project for you. Load the project on HOME first, then start the song.
              

              The device holds 16 songs in its song storage, the flash area that used to hold samples. The workbench's Song mode group reads, writes, deletes and exports them. The device itself never edits a song.
              

              Playing a song on the device
              

                

              1. Hold SEQ for about 0.6 s, or press SEQ+EDIT, to open ACTIONS.
                2. 

              2. Turn K5 or K1 to SONG MODE and press the 4th button in the left group (after SHIFT, FADER BANK, HOME). The SONG page opens.
                3. 

              3. Turn K5 or K7 to choose song 1 to 16. This works while the song is stopped. The bottom line of the page says K5/K7 SONG.
                4. 

              4. Press PLAY. The song starts at row 1. If the project's pattern sequencer was running it stops. Press PLAY again to stop. Every note is released and MIDI Stop is sent once.
                5. 

              5. HOME leaves the page. The song keeps playing.
                6. 

              

              In the browser simulator the Song mode shortcut on the Play & edit tab opens the same page.

              How the song ends
              

              With Loop the song off, the song stops after the last row, releases every note and sends MIDI Stop. With Loop the song on it continues from the Loop start row. When tracks are detached by a launch (chapter 05) the song does not stop at its end. The following tracks go silent, the page shows SONG OVER, the launched tracks keep looping and the clock keeps running until you press PLAY.
              

              The song editor in the workbench
              

              In Projects & sounds, open Song mode (Classic Tabby). Choose the Target: Device (project library) or Browser simulator. Choose the Song slot. Read song loads the slot into the editor. New song starts an empty one. The editor shows the name, project slot, BPM, the loop boxes, the loop start row, where jumps land, the output channels, the row table (one line per row with the eight block ids, Repeat, Steps and Loop here), Add row and Remove last row, the row events, and the block editor. Write song writes the song record first, then every block in the editor in batches, then reads the record back and compares. Delete song clears the slot. Storage status asks the device how much room is left.
              

              Writing to a slot that already holds a song deletes the old song first. The page says so and suggests an Export .tabby of the old song before you confirm.
              

              

              04 · Scene changes
              

              A scene change is a jump to another row while the song plays. You queue it from the pads of the SONG page.
              

                

              1. On the SONG page, read PADS ROW a - b. Pad 1 is row a, pad 16 is row b. OCT− and OCT+ move the window by 16 rows, up to row 128.
                2. 

              2. Press the pad of the row you want. The page shows JUMP TO ROW n in amber at once.
                3. 

              3. The jump lands on the next bar when JUMP: NEXT BAR is shown, or when the current row has played all its repeats when JUMP: ROW END is shown. K4 switches between the two. The setting is saved in the song as Jumps land at.
                4. 

              4. At the landing the page shows ROW n and X 1, every track starts the new row's blocks together, and the new row's events have been sent before its first notes.
                5. 

              

              What to expect
              

                

              • Press several pads inside one bar and only the last one lands. Press the same pad ten times and one jump lands.
                • 

              • A pad with no row behind it, or a press while the song is stopped, shows NO SUCH ROW / NOT PLAYING and queues nothing.
                • 

              • A jump cancels every pending track launch, stop and return (chapter 05) and brings every launched or stopped track back to the song at the landing. Notes of launched tracks are released at the landing.
                • 

              • A jump queued inside the last half step before the bar can land with its notes and events a little late. LATE counts up by one on the page.
                • 

              • The pads do not light differently on the SONG page. The screen is the feedback.
                • 

              • A row with Loop here never moves on by itself. Use a jump to leave it.
                • 

              

              

              05 · Track launching
              

              Track launching lets one track leave the song and loop one of its patterns while the others keep following the rows. A track's pattern N is simply the block that track has in row N, played for row N's step length. Nothing extra is stored.
              

              The TRACK LAUNCH page
              

              Start the song on the SONG page, then press SCL. The TRACK LAUNCH page opens and the SCL lamp lights. SCL again returns to the SONG page. HOME leaves to the overview. The page shows:
              

                

              • LAUNCH, the selected track in its colour, and BAR n, the bar counter since PLAY. This counter never resets while the song runs.
                • 

              • One column per track: the pattern row it plays or -, then a word. FOLLOW means it follows the song. PLAY in green means it loops a launched pattern. STOP means it is stopped. Q n in amber means pattern n is queued. >STOP means a stop is queued. >SONG means it returns to the song at the next bar.
                • 

              • PATTERNS a - b with OCT PAGE, and 16 cells for the pads. A numbered cell is a pattern the selected track has on that row. A green cell is the one playing, an amber cell the one queued, an empty cell no pattern.
                • 

              • ROW n, the song's current row, then SONG OVER when the song has ended with detached tracks, and LATE n.
                • 

              • STOPPED - PLAY STARTS THE SONG when the song is not running. PLAY starts and stops the song here as on the SONG page.
                • 

              

              Selecting a track
              

              Hold SHIFT and press pad 1 to 8. The pads show the track colours while SHIFT is held: dim for a track at rest, bright for a track with a pattern playing, flashing for a track with something queued, and one level brighter for the selected track. Pads 9 to 16 keep their usual mute function under SHIFT.
              

              Queuing a pattern
              

              Press the pad of a pattern. The pad flashes green, the column shows Q n and the notice says LAUNCH AT NEXT BAR. On beat 1 of the next bar the pattern starts, the pad turns steady green and the column shows PLAY. If the track was playing another pattern, that pattern's notes are released at the bar. A second press inside the same bar replaces the queued pattern. The launched pattern loops with its own length, so a 48-step pattern against 16-step rows lines up again every three bars.
              

              Stopping a track
              

              Press the green pad, the pattern that plays. It flashes red, the column shows >STOP and the notice says STOP AT NEXT BAR. At the bar every note of the track gets its note-off on the channel it was sent on, the pad goes dim and the column shows STOP. A stopped track stays silent until you launch a pattern or send it back to the song. Stopping every track never stops the transport, the clock or the Song Position Pointer.
              

              Back to song
              

              ENV queues the selected track back to the song: the column shows >SONG and the notice TRACK BACK TO SONG AT BAR. At the next bar the track joins the row the song is in at that moment and shows FOLLOW. SHIFT+ENV does it for every track at once (ALL TRACKS BACK TO SONG AT BAR). With the song stopped the notice says NOT PLAYING.
              

              Paging and messages
              

              OCT− and OCT+ turn the pad page in steps of 16 rows. The messages are: PLAY STARTS THE SONG FIRST when the song is stopped, NO PATTERN ON THIS PAD when the row has no block for the selected track, LAUNCH AT NEXT BAR and STOP AT NEXT BAR when a queue was taken.
              

              Pad colours and flashing
              

              PadMeaning
              

              OffNo pattern for the selected track on that row.
              

              Dim whiteA pattern that is not playing.
              

              Steady greenThe pattern that plays.
              

              Flashing greenThe pattern queued to start at the next bar.
              

              Flashing redThe playing pattern, with a stop queued.
              

              Track colours (with SHIFT)Pads 1 to 8 are the tracks. Dim at rest, bright while a pattern plays, flashing while something is queued, brighter for the selected track.
              

              

              While the song runs the flashing follows the master clock, one change per eighth note. With the song stopped the pads flash every quarter second.
              

              Scenes and launched tracks
              

                

              • A scene change on the SONG page overrides everything queued on the TRACK LAUNCH page and brings every track back to the song at the landing.
                • 

              • A launched or stopped track ignores row changes until it returns.
                • 

              • When the song's last row ends and no track is detached, the usual song end applies. When a track is detached, the following tracks go silent, SONG OVER appears, the detached tracks keep looping and the clock keeps running. PLAY stops everything and sends MIDI Stop.
                • 

              • Every launch, stop and return lands on beat 1 of the next bar of the master clock, 16 steps long, whatever the row lengths.
                • 

              • A press inside the last control cycle before the bar cannot be served on that bar. The pattern enters at the next cycle in phase, its downbeat skipped, and LATE counts up by one.
                • 

              • A launch sends the program change of the pattern's row for the track's channel, Lead ms before the bar (chapter 08).

              06 · Importing MIDI files
              

              The panel Import MIDI file (Classic Tabby) in Projects & sounds turns a Standard MIDI File (type 0 or 1, including Renoise exports and mf2t text) into a song. Everything happens in the browser. Nothing is sent until step 6.
              

              Step by step
              

                

              1. 1. MIDI file. Choose the .mid file. The summary shows the format, ticks per quarter note, tracks, parts, bars, the meter and the tempo. File warnings appear under it.
                2.

Assign each part to track 1 to 8 or skip it. Several parts may share a track; the 4-notes-per-step limit then applies to the mix. Drum parts on channel 10 are marked. Under the table, OUT CH per track sets the output channel written into the song header; device keeps the device's OUT CH for that track.
                3. 

              3. 3. Options. Bars from and to cut the range. Bars per row offers only lengths that stay on bar lines. Row events chooses the pre-roll for program changes and CCs (one beat before, at the row start only, or up to one bar before). More than 4 notes on a step keeps the 4 loudest, highest or lowest. Then the song name, the project slot, loop the whole song, and loose block matching with its velocity tolerance.
                4. 

              4. 4. Resulting song. The statistics line and the row table, then Dropped or changed: the warning list.
                5. 

              5. 5. Browser song. Save song (JSON) keeps the model on your computer. Export .tabby file writes the device file format. Load song JSON brings a saved model back.
                6. 

              6. 6. Write to the device or the simulator. Choose the Song slot, read what the slot holds, click Write song… and confirm. The target follows the Target choice of the Song mode group above (device or browser simulator). The panel then shows the batch plan and the time taken.
                7. 

              

              Track assignment and output channels
              

              The first eight non-empty parts are pre-assigned to tracks 1 to 8. A part's notes are stored in the row and step where they start. A note is anchored to the nearest 16th step and keeps its offset and length, so a part keeps its feel. OUT CH per track decides which channel the device sends that track on while the song plays. Set it to the channel of the gear that should play the part, or leave device to use the SEQ page setting.
              

              Exact timing and the quantize option
              

              Timing is kept to 1/480 of a 16th step. Files with 96, 120, 192, 240, 384, 480, 960 or 1920 ticks per quarter note convert exactly. Other resolutions round to the nearest unit and the panel reports the largest rounding. Quantize snaps starts to the grid, or starts and ends, and only then the rules for note ends apply.

              Deduplication
              

              Identical cells (the same notes, velocities, offsets and lengths) become one block id. Rows that repeat the same eight ids merge into one row with a repeat count. The merge loses nothing. Loose block matching also merges cells whose only difference is velocity, within the tolerance you set, and lists every merge.
              

              Writing and replacing a song
              

              Writing uses the song editor's path: an occupied slot is deleted first, then the song record goes, then the blocks in batches, then the record is read back and compared. The old song's blocks are reclaimed at the next compaction. Export a .tabby of the old song first if you want to keep it. Projects are never changed by a song write.
              

              

              07 · Timed notes
              

              Offsets and lengths
              

              Every note in a block carries a start offset and a length in units of 1/480 of a 16th step. The offset says how far before or after its step the note starts, from −240 to +240 units, which is half a step either way. A note belongs to the step nearest its start. The length is exact up to 65535 units, which is 8.5 bars of 4/4. The units are musical, so they scale with the tempo. At 120 BPM one unit is about 0.26 ms and one step is 125 ms.
              

              Reading them in the song editor
              

              In the block editor each step is a text field: pitch:velocity:length/offset. The length is in steps and may have decimals. The offset is in signed units. A trailing r means retrigger, @n a probability of n out of 8, and ! the alternate tuning. For example 60:100:1.5/-20 is a C4 at velocity 100, one and a half steps long, starting 20 units early. A step with an offset or a fractional length has an orange mark on its left.
              

              Editing them
              

              Click a step to open the inspector under the grid. It lists each note with its pitch, velocity, retrigger, offset (in units, with the fraction of a step and the milliseconds at the song's tempo) and length (steps and units). Change a value and the readouts follow. Quantize starts to 16ths clears every offset in the block. Quantize starts and ends to 16ths also rounds every length to whole steps. Store block keeps the edited block in the editor and Write song sends it to the device.
              

              Swing and old songs
              

              Songs written by tabby-v02.0 keep playing exactly as before, project swing included. When you write such a song again from the workbench it is stored in the new format and plays straight, whatever the project swing. Tick Swing follows the project setting in the song editor and write it again to make it swing. The swing itself is the project's SWING setting on the SYNC / MIDI page (SEQ, K3).
              

              

              08 · Program changes and CCs
              

              A row can carry events: program changes, bank selects and control changes. They fire when the row is entered, before the row's first notes, on every MIDI out port, addressed to a MIDI channel. The gear on that channel is described in the rig setup, so the editor can show preset names instead of numbers.
              

              The rig setup table
              

              In Projects & sounds open Rig setup (Classic Tabby). The table has one line per MIDI channel: Device (from the device library), Name (your name for it), Gap ms, Lead ms, Numbering (how the device counts programs and banks) and Names… for your own program names. Profile name, Export rig (.json), Import rig and Reset are above the table. The profile is saved in this browser. A song can carry its own copy of the rig; the row event editor has a box for that, and the copy travels in the .tabby file.
              

                

              • Gap ms is the pause the device needs after a program change or bank select. Blank uses the device definition. The gap becomes gap events in the song when it is written, so the device pre-fires the stream early enough for the last message to leave before the bar.
                • 

              • Lead ms makes the program change leave that long before the bar. It applies to track launches and scene changes alike. 0 sends it with the downbeat. Use it for gear that takes time to switch.
                • 

              

              The device library
              

              The library has definitions for the E-MU Proteus/2 XR, Eventide H90 Harmonizer, Zoom MS-70CDR+, Waldorf Blofeld, Waldorf Pulse 2, Dirtywave M8 Tracker Model:02, Korg volca fm2, Instruo Seashell and the M-VAVE FM-1 under the Skiff, Melodee and Orange Cat firmwares. Each one gives the program numbering, the bank scheme, named controllers and the preset names the manufacturer publishes. Unverified fields are marked and shown in the editor.
              

              Row events in the song editor
              

              Below the row table of the song editor, the Row selector picks a row. Row 1 is marked SEND SETUP because its events are the set-up list. The list shows each event with its channel, the device on it and the event in words. Arrows move an event, ✕ deletes it. Add on channel and type add a Program (from the preset list, with a bank where the device has banks, or a raw number), a Control change (named or raw, with the value meaning where known) or a Gap in ms. A row holds up to 32 events and a song up to 292. Gaps read back from the device are shown greyed and regenerated from the rig at the next write.
              

              SEND SETUP
              

              With the song loaded and stopped, open ACTIONS, choose SEND SETUP and press the 4th button in the left group (after SHIFT, FADER BANK, HOME). Row 1's events go out at once and the notice says SETUP SENT - ROW 1 EVENTS. Use it before a set, after a power-up, and before PLAY on a song whose first row has gaps. With the song playing it says STOP THE SONG FIRST. With no song loaded it says NO SONG LOADED.
              

              What goes out when
              

                

              • A row change or a scene change sends the new row's events for every channel, with their gaps, pre-fired so the last message leaves before the bar.
                • 

              • A track launch or a return to the song sends only the events of the pattern's row that address that track's channel, Lead ms before the bar. Two tracks on one channel each send their own.
                • 

              • LATE on the SONG page counts rows whose stream ended after the bar line, for example PLAY on a row with gaps without SEND SETUP first, or a jump queued with less time left than the gaps need.
                • 

              • Events reach external gear only. The SMK-37's own presets are set by the project, not by events.
                •

              11 · Storage
              

              The song pool
              

              Song storage is the flash area that held the sample bank and the DX7 user library on V01. It holds 16 song records and a pool of 80 block sectors (96 before tabby-v04.0 moved the storage). Blocks of every song share the pool. A freshly erased area reports 326080 bytes free. Storage status in the Song mode group shows the free bytes, the reclaimable bytes, and the state of the loaded song: its event count, the late count and every track's state.
              

              Compaction
              

              Writing a song again, or deleting one, leaves its old blocks in the pool as garbage. They keep their bytes until a compaction. Storage status shows them as reclaimable. To reclaim them, open ACTIONS, choose COMPACT SONG STORAGE and press the 4th button in the left group (after SHIFT, FADER BANK, HOME); the screen asks COMPACT SONG STORAGE? and a second the 4th button in the left group (after SHIFT, FADER BANK, HOME) confirms. The SONG page shows COMPACTING STORAGE... for a few seconds. One sector is rewritten per control cycle, with a short audio dip per sector if something plays. The action is refused while a song plays. When the pool is full during a write, the device compacts the most rewarding sector by itself.
              

              Exporting and importing .tabby files
              

              Export .tabby in the song editor saves the song as one file: the song record and every block, plus the song's own rig copy when it has one. Import .tabby loads such a file into the editor; click Write song to put it on the device. The MIDI importer's Export .tabby file writes the same format. Files from tabby-v02.0 load and are written back in the current format.
              

              Writing pauses audio briefly
              

              Every flash erase and write silences the audio for a moment. A song write makes a few pauses at the end of each batch of blocks. Write songs before the set, not during it.
              

              Restore factory V16 overwrites the last 40 KB of song storage, block sectors 86 to 95. Export every song as a .tabby file before you restore the factory firmware. Projects are stored elsewhere and are not affected by songs at all.

              13 · 三分钟上手（合成器）
              

              网页顶部和实机开机画面显示版本；HOME 显示 KEY 或 PAD 哪个是当前的演奏焦点。开机动画约 1 秒，按键或旋钮可跳过；开机不会自动播放。
              

              Classic Tabby 有 8 条轨道、5 种音源、16 个用户项目槽。每轨支持 16、32、48 或 64 步；常用操作使用单键，完整细调放在长按菜单和网页里。
              

              1. 准备试听。实机把 K8 放在适中的位置；网页点琴键或播放即可发声，无需额外开关。
              2. 先听一个预设。在 HOME 总览直接转 K7 切换整套预设，按 PLAY 播放。也可按 HOME 打开列表，转 K7／K5 直接载入，PLAY 载入播放。左侧按键组第 4 键（SHIFT、FADER BANK、HOME 之后）打开项目保存，打击垫 1–16 也能直接选对应预设。
              3. 改声音。回总览后 K5 选轨；DX7 轨短按 EDIT 进入快捷页，转 K7 换音色，K6 换 A–D 音色组，K1–K4 调算法／反馈／移调／音量，再按 EDIT 返回。其他音源的音色在网页工作台编辑。想换音源，在总览转 K6 或 K2，左侧按键组第 4 键（SHIFT、FADER BANK、HOME 之后）应用。

              5. 调平衡。按 MIX 进入混音，打击垫 1–8 静音、9–16 独奏；K5 选轨，K1–K4 调四轨音量。再按 MIX 或 HOME 返回。

              操作用途
              

              HOME从编辑页回八轨总览；已经在总览时打开预设，再按取消。
              

              K5总览、DX7 快捷页、SYNC / MIDI、MIDI TRACK 和混音页选轨；菜单选项目；SONG 页选歌曲。
              

              K7总览直接切换整套工程预设；DX7 快捷页选当前轨音色；预设列表选工程；SEQ 选步；保存页选存档槽；SONG 页选歌曲。
              

              K6总览选择合成引擎，左侧按键组第 4 键（SHIFT、FADER BANK、HOME 之后）应用、HOME 取消；SEQ／ARP／FX 翻参数页；DX7 快捷页切换 A–D 音色组。
              

              K1 / K2 / K3 / K4总览：音量／音源／步位置／速度。SEQ 基础页：音量／步位置／音高或鼓声部／速度。其他页看屏幕底部标签。
              

              EDIT 短按／长按DX7 轨短按进入或退出快捷页（K7 选音色，K6 换音色组，K1–K4 调算法／反馈／移调／音量）。其他音源按 EDIT 时屏幕提示 VOICE EDIT MOVED TO WORKBENCH，音色在网页工作台编辑。
              

              SEQ 短按／长按在任何页面短按打开 SYNC / MIDI 页；SHIFT + SEQ 打开 MIDI TRACK；长按约 0.6 秒打开 ACTIONS 菜单；HOME + SEQ 拍击速度。
              

              MIX单按进入／退出混音。打击垫 1–8 静音、9–16 独奏，无需一直按住 MIX。
              

              PLAY / REC播放／暂停／续播。本版本 REC 不录音（屏幕提示 NO REC IN THIS VERSION）。预设页的 PLAY 为载入并播放，切换预设不弹确认。
              

              左侧按键组第 4 键（SHIFT、FADER BANK、HOME 之后）打开保存页，再按保存；菜单中用于执行／确认。HOME 取消。
              

              OCT− / OCT+演奏时上下移调八度；SONG 与 TRACK LAUNCH 页翻打击垫页。
              

              ENV / SHIFT + ENV / FX / SCLFX 按轨调混响和延迟。SCL 在 SONG 与 TRACK LAUNCH 页之间切换；ENV 让所选轨回到歌曲，SHIFT + ENV 让全部轨道回到歌曲。在其他页面，SCL、ENV 和 SHIFT + ENV 只提示音色编辑已移至网页工作台。
              

              ARP短按开关当前轨琶音／鼓连奏；长按约 0.6 秒打开参数页。K5 选轨，K6 翻页：分频／方向／音域／门长，Swing／Hold。
              

              

              37 个力度琴键始终用于演奏。短按 PAD / STEP 切换 KEY／PAD 编辑焦点（本版本没有 Pad 步进模式）；菜单中打击垫用于选择。8 个编码器从左起依次为 K1–K8（固件把 K5 叫 SELECT、K6 叫 PAGE、K7 叫 PRESETS、K8 叫 MASTER）。4 个推子控制轨道音量，FADER BANK 在 1–4／5–8 轨之间切换，推子经过屏幕当前值后才接管。BT 键提示蓝牙设置已移至网页工作台，SHIFT + HOME / SRC 直达音源页。弯音轮、调制轮和延音踏板跟随 KEY；Pad 触后跟随 PAD。
              

              总览的 K4 设置速度（BPM 只在这里设置）。本版本机身没有录音和步进编辑；歌曲在网页工作台编写。
              

              同一轨的静音与独奏互斥：开启独奏会取消该轨静音，开启静音会取消该轨独奏；其他轨保持原状态。
              

              网页操作
              选择预设后点“播放”试听。“读取与保存”管理设备读取和浏览器存档，“文件与 MIDI”导入、导出项目和音色。
              常用编辑按钮直接打开音色、SYNC / MIDI、混音和效果；其余功能在“更多编辑”。旋钮可拖动或滚轮调节，LCD 数值可点击编辑。电脑键盘 Z、S、X、D…演奏，空格播放，Esc 停音；输入文字和操作菜单时不会演奏。
              

              上排功能键在所有页面都有效：FX、EDIT（DX7 轨）、MIX、SEQ 可直接切页；SCL、ENV、LFO 只在歌曲页有作用（见第 05 章）；ARP 短按开关、长按调参数，PLAY 控制播放。左侧按键组第 4 键（SHIFT、FADER BANK、HOME 之后）打开项目保存页，或执行屏幕内的确认；OCT−／OCT+ 调八度。离开确认页不会执行待确认操作。
              

              LCD 数值直接编辑
              把鼠标放在 LCD 上的数值，出现高亮即可滚轮调节；每次按参数最小步长变化，不随滚动速度加速。也可点击打开大号数值框，用滚轮、＋／−或方向键细调，Esc 关闭。支持底部参数、顶部 BPM、总览各轨音量、DX7 快捷页的参数行和效果参数行。混音页也可点静音／独奏格子设置。状态、电平和当前引擎不支持的参数只显示；外部 MIDI 时钟下 BPM 由外部控制。切换轨道或参数页会关闭旧编辑框，避免改错参数。总览调其他轨的小音量数字不会改变当前选轨。
              

              MIX 短按（小于 0.6 秒）进入或退出混音；按住 0.6 秒可临时查看混音，松开回原页。MIX、EDIT、SEQ、ARP 的长按过程中，屏幕顶部显示进度条。
              

              SHIFT + Pad 1–8 直选轨道，SHIFT + Pad 9–16 切换对应轨道静音；上半区高亮当前轨，下半区橙色表示静音。松开 SHIFT 恢复原来的打击垫功能。
              SHIFT + SEQ 直达 MIDI TRACK：K1 IN CH 选输入通道，K2 OUT CH 选输出通道，K3 SEQ 选 LOCAL／BOTH／MIDI，K4 OUT PORT 选 ALL／OFF。输入、输出通道独立；多个轨道可共用输入通道。
              SHIFT + HOME 音源页的 K2 TRACK 即时选择 PROJECT／LIVE／OFF：PROJECT 跟随项目，LIVE 在换项目时保留音色和按住的音符，OFF 释放音源内存。原来的 NORMAL／PLAY 设置分别对应 PROJECT／LIVE。LIVE 音色请单独导出；项目保存的是原有编曲。模式与输入通道自动记忆；修改前请先停音。K1 仍只预览音源，左侧按键组第 4 键（SHIFT、FADER BANK、HOME 之后）应用音源，HOME 返回。
              组合键
              HOME＋PLAY 紧急停音回起点；HOME＋左侧按键组第 4 键（SHIFT、FADER BANK、HOME 之后）撤销／重做；SEQ＋EDIT 打开更多菜单。都可以从长按 SEQ 的菜单完成对应操作。网页需要锁住按键时可 Shift 点击或右击，再点释放；日常操作无需使用。
              

              15 · 同步与 MIDI
              

              内置 128 个 DX7 格式预置音色，分为 A–D 四组，每组 32 个。网页工作台可把标准 DX7 单音色或 32 音色 SysEx 导入某一轨，不支持扩展参数。机身不再有 DX7 用户音色库。
              

              在任何页面按 SEQ 打开 SYNC / MIDI 页：K1 CLOCK 选 INT／MIDI，K2 CLK IN 选时钟来源（AUTO、USB、BLE、DIN），K3 SWING，K4 SEQ OUT 选 OFF／ON／CLOCK，K7 开关 KEY OUT。速度只在 HOME 的 K4 设置；外部 MIDI 时钟下速度由外部设备决定。长按 SEQ 打开 ACTIONS。
              

              切换时钟会停止播放；MIDI 模式需外部 Start／Continue 和 Clock，等待时屏幕提示 WAIT MIDI CLOCK。外部 BPM 只读。歌曲模式需要 INT 时钟。
              

              首次使用时，8 个轨道的 SEQ 默认 BOTH，KEY OUT 默认 ON，同时启用 ALL 和 SEQ OUT ON；已保存的输出模式与 KEY OUT 选择会保留。MIDI TRACK 页（SHIFT + SEQ）：K1 IN CH 输入通道，K2 OUT CH 发送通道，K3 SEQ 选 LOCAL／BOTH／MIDI，K4 OUT PORT 选 ALL／OFF。SYNC / MIDI 页：K4 SEQ OUT 选 OFF（关闭音序音符和主时钟）／ON（音序音符及内部时钟／启停）／CLOCK（仅内部时钟／启停），K7 开关 KEY OUT。SEQ 模式与 SEQ OUT 不影响 ARP；ARP 固定 BOTH（内部发声＋MIDI 输出），按该轨 OUT CH 和公共 OUT PORT 发送。切换 SEQ 设置不打断 ARP，开关 ARP 也不释放 SEQ 音符。ARP 第二页仅保留 SWING、HOLD 和 OUT CH，K3 无功能。只发时钟时，请关闭 KEY OUT 和各轨 ARP。USB-C 分轨输出时逐轨设置 OUT CH，启用 BOTH 或 MIDI、ALL 及 SEQ OUT ON；只改 IN CH 不会改变输出通道。升级后本地演奏始终可用，Thru 关闭；旧端口组合只要有输出就转为 ALL，OFF 保留。偏好独立于项目；网页仅预览，实机请通过机身设置。
              

              琶音：速度、方向、Swing 与 Hold
              短按 ARP 开启后按住音符；长按 ARP 打开参数。K6 翻两页：第一页 K1 为 1/4、1/8、1/16、1/32 分频，K2 方向，K3 为 1–4 个八度，K4 为 25%–100% 门长；第二页 K1 为 0%–50% Swing，K2 开关 Hold。Hold 保持松手后的和弦，全部松手后弹新和弦即可替换；关闭 Hold、停止或紧急停音会释放锁住的音符。K5 选轨，各轨参数独立。HOME／SEQ 基础页 K4 调 BPM；外部时钟需 Start／Continue 和 Clock，Swing 按 24 PPQN 的精度变化。
              808 支持分频、方向、Swing 和 Hold；音域与门长显示“--”，不移调鼓声部。ARP 开关与六项参数随项目保存，按住或 Hold 锁住的音符不保存。
              

              本版本移除的机身编辑
              tabby-v04.0 移除了机身的步进编辑：STEP DETAILS、LOCKS、RHYTHM/REC 页，REC 录音（停止时逐步录入和播放时录入）、预备拍、节拍器、Pad 步进模式，以及复制、粘贴、清空、重复步进和对应的 ACTIONS 项。项目里原有的图案仍随项目载入、保存和播放。SWING、时钟、时钟来源与输出开关移到 SYNC / MIDI 页，速度在 HOME 的 K4。节拍器与预备拍计划在之后的版本（第 5 阶段）回来。
              

              

              16 · 五种音源
              

              每条轨道都能选择任意一种音源，同类型的多条轨道也各有参数。切换音源后使用新类型的默认参数；鼓与旋律互换会清空不兼容步进，可用 HOME＋左侧按键组第 4 键（SHIFT、FADER BANK、HOME 之后）撤销。
              

              音源怎样编辑
              

              DX7 · FM短按 EDIT 进入快捷页：K7 选 1–128 音色，K6 切换 A–D 组，K1–K4 调算法／反馈／移调／音量。再短按返回。算子级编辑和 .syx 导入在网页工作台完成。
              

              303 · 酸性贝斯参数在网页工作台编辑：Cutoff／Reso／EnvMod／Decay；Accent／Wave／Tune／Volume；Drive／DrvTyp／Slide／AccDec；Mono／Poly 选择单音滑音或 4 复音。Program Change 0／1 切换锯齿／方波。
              

              808 · 合成鼓11 个鼓声部与 KIT 的参数在网页工作台编辑；各声部可调参数不同，KIT 调整整套鼓组。机身用琴键或打击垫试听并选中声部。
              

              PSG · 芯片音色网页工作台编辑 MODE（YM／AY／NOISE／MIX）、NOISE、TUNE、RELEASE。纯方波模式下 NOISE 不改变声音。
              

              PLUCK · 拨弦网页工作台编辑 DECAY、BRIGHT、TUNE、RELEASE。DECAY 是自然衰减，RELEASE 是松键衰减；按住键仍会自然衰减。亮度在下一次拨弦生效。
              

              

              包络与 LFO
              机身的 ENV 与 LFO 页已随音色编辑移至网页工作台；各引擎的包络（FM 的 ADSR、303 的 EnvMod／Decay／AccDec、PSG 与 Pluck 的 Release 等）和非 FM 引擎的轨道 LFO（速度、深度、音量起伏／声像、波形）在网页里编辑，随项目与轨道音色保存。LFO 作用于整个轨道，也影响轨道效果发送。效果使用 FX。
              

              DX7 音色名
              机身的 DX7 PATCH NAME 页已移除；音色名随网页工作台导入的 .syx 音色一起写入，并随项目保存。切换 DX7 内置音色会替换当前编辑。
              

              轨道效果
              按 FX，K5 选轨；K1 混响发送、K2 延迟发送，0 即关闭该轨发送，五种音源均可用。K3 轨道音量、K4 共用效果返回量。转 K7 到第二页细调：K1 混响时间、K2 延迟时间、K3 反馈、K4 返回量，由所有轨道共用。轨道发送量随项目和轨道音色保存；共用效果参数仅随项目保存。静音停止新发送，已有尾音自然衰减。
              

              

              17 · 音量与混音
              

              K8 是总输出音量。实机旋钮控制合成器、USB 与蓝牙输入的最终输出，也影响 USB 录音。最小位置静音，切换项目沿用旋钮位置；它不随项目保存。转动时屏幕短暂显示 MASTER 百分比或 MASTER MUTED。
              轨道 LEVEL 是项目里的混音音量。在 HOME／SEQ 基础页用 K1 调当前轨。303 的 Volume、808 的声部 Level 和采样 Level 用于音色内部的平衡。
              

              1. 按一下 MIX 进入混音，按打击垫 1–8 切换对应轨静音。
              2. 按一下 MIX 进入混音，按打击垫 9–16 切换对应轨独奏。
              3. 混音页中，K5 选轨；K1–K4 调当前四轨组（1–4 或 5–8）的音量。
              

              多个轨道可以同时独奏；同一轨的静音与独奏互斥。
              网页“静音”只关闭试听，编辑与音序仍继续。要停回起点，请用 HOME＋PLAY 或“紧急停音”。
              

              

              18 · 保存与文件
              

              工作区 ≠ 已保存项目。实机未保存的编辑只在内存中，重新开机或载入其他项目会丢失。网页与实机各有自己的存档；“保存到设备”会完成传输、写入槽位和读回校验。
              

              预设与保存分开操作
              PROJECT 轨的音色修改随项目保存；LIVE 轨的音色修改请导出轨道音色。项目备份不包含歌曲；歌曲用“导出 .tabby”逐首备份。
              直接切换：在 HOME 总览转 K7 即可切整套预设，屏幕显示当前工程名称；播放中切换会继续播放，停止时切换保持停止。切换直接生效，不提示保存。单轨音色在 EDIT 页用 K7 选择。
              浏览列表：总览按 HOME 打开用户项目列表（16 个用户槽）。K7／K5 直接载入对应编号，PLAY 载入并播放，左侧按键组第 4 键（SHIFT、FADER BANK、HOME 之后）打开项目保存；打击垫 1–16 直接选编号并沿用之前的播放状态。空 USER 槽会提示，不替换当前项目。
              切换预设会直接替换当前工作区，包括未保存的修改；想保留修改时，先按左侧按键组第 4 键（SHIFT、FADER BANK、HOME 之后）保存。
              保存：左侧按键组第 4 键（SHIFT、FADER BANK、HOME 之后）打开保存页，K5／K7 选 USER 槽，K1 选名称字符、K2 改字符；再按左侧按键组第 4 键（SHIFT、FADER BANK、HOME 之后）写入。覆盖其他已有槽须再按左侧按键组第 4 键（SHIFT、FADER BANK、HOME 之后）确认，成功后自动回原页面，HOME 取消。当前槽直接更新。标题星号表示未保存。
              

              顶部状态区区分浏览器试听、设备连接和未写入的网页修改。连接不会自动读取或同步；点常用区“读取设备项目”替换网页工作区，误操作可用 HOME＋左侧按键组第 4 键（SHIFT、FADER BANK、HOME 之后）撤销。保存并读回校验一致后才显示已写入；仅存到浏览器不代表写入设备。实机旋钮修改后，请重新读取。
              项目保存各轨 ARP 开关与参数。
              

              把网页作品放入 SMK37 OPEN
              1. 用 USB 数据线连接 SMK37 OPEN；在网页完成编辑，点顶部“保存到设备”。
              2. 允许浏览器 MIDI／SysEx，选择目标槽位，点击“保存并校验”。已有槽位内容会被替换。
              3. 看到“读回校验通过”再断开设备。重启后可在 USER 列表载入对应槽；不需要另外按实机左侧按键组第 4 键（SHIFT、FADER BANK、HOME 之后）。
              

              “读取设备项目”把当前实机工作区带入仿真；“恢复到工作区”也不会自动覆盖设备槽。网页面板的左侧按键组第 4 键（SHIFT、FADER BANK、HOME 之后）写入浏览器本地槽，清理浏览器数据会删除这些存档，重要作品请导出。
              

              文件包含什么
              .fm1完整八轨项目：音源、参数、轨道音量、循环长度、步进等；不含歌曲。
              .fm1t一条轨道的音源类型、音色参数和音量；不携带步进。支持全部六种音源。
              .syxDX7 标准音色，支持单音色和 32 音色库。设备目标轨须设为 DX7。
              .tabby一首歌曲：歌曲记录与全部块，可带该歌曲自己的设备配置副本。见第 11 章。
              

              项目库列表读取失败时，载入、保存和导入按钮保持禁用；点击“刷新列表”重试。只有完整读取成功后才开放操作，重试会保留有效的选中槽位。
              

              19 · MIDI、蓝牙与时钟
              

              USB 与网页连接
              下载完整 HTML 后可离线试听和编辑；读写设备需要支持 Web MIDI 的电脑 Chrome／Edge 和 USB 数据线，并允许 MIDI／SysEx。不能连接时先关闭占用 MIDI 的其他网页或软件，再重新连接。外部演奏请选择与目标轨相同的输入通道；SHIFT + SEQ 后用 K2 查看或修改。
              仿真页的“连接 MIDI 输入”用于外部键盘演奏网页。项目库连接用于读写实机项目和音色。USB 音频的输入／输出选择在电脑系统或音乐软件中设置。
              

              USB MIDI 开机即接收；蓝牙 MIDI 在网页工作台“项目与音色 → 蓝牙设置”中控制，两者使用相同的轨道输入通道设置。当前 Pro／Elite 没有有线 MIDI IN，机身 MIDI OUT 用于输出。
              

              通道与接收规则
              默认 CH1–7 对应轨道 1–7，CH10 对应轨道 8。SHIFT + SEQ 后用 K2 为各轨选择输入通道 1–16。音符、弯音、调制和控制器按此设置接收，与屏幕选中轨道无关；多轨可共用一个通道叠奏。未分配给任何轨道的通道消息被忽略。更换音源不改变通道，USB MIDI 与 BLE MIDI 使用相同规则。
              例如在默认设置下，键盘 CH2 控制轨 2；将轨 3 的输入也设为 CH2，即可同时演奏轨 2 和轨 3。
              

              接收消息作用与范围
              

              Note On / Off全部音源接收 Note On／Off 和力度；Note On 力度 0 等同 Note Off。808／SAMPLER 按鼓音符选择声部。
              

              Pitch BendFM、303、PSG、Pluck 支持 14 位弯音，中心 8192，范围 ±2 半音；作用于已发声及后续音符。808／SAMPLER 的音高使用各声部 TUNE。
              

              CC1 · Mod WheelFM：音高颤音，音色 PMS 为 0 时调制轮仍有基础响应；303：EnvMod；PSG、Pluck、808、SAMPLER：轨道 LFO 深度，未设置 LFO 时为音量起伏。
              

              CC7 / CC10 / CC11 / CC91全部音源：CC7 轨道音量；CC10 声像（0 左、64 中、127 右）；CC11 表情（0 静音、127 原音量）；CC91 混响发送。
              

              CC64 / Channel Pressure / CC2 / CC4FM、303、PSG、Pluck：CC64 延音，64–127 踩下，0–63 松开。FM 另接收通道触后用于颤音，以及 CC2／CC4 的振幅控制，效果取决于音色振幅敏感度。
              

              CC120 / CC121 / CC123CC120 停止该轨声音；CC123 释放该轨外部音符（延音踏板仍有效）；CC121 复位实时弯音、表情、声像、调制和踏板，不改音色参数。
              

              Program ChangeProgram Change 使用 SMK37 OPEN 音色：FM 0–15 循环；303 0／1 为锯齿／方波；PSG 0–3 为 YM／AY／NOISE／MIX。其他音源忽略。部分软件显示为 1 起始编号。
              

              Engine CC303 还接收 CC5 滑音时间、CC71 共振、CC74 截止、CC75 衰减；PSG 接收 CC74 噪声、CC72 释放；Pluck 接收 CC74 亮度、CC75 衰减、CC72 释放。
              

              CC7、CC91、音色切换与音色参数编辑可随项目保存。弯音、表情、声像及实时调制不写入项目；CC121 不撤销已编辑的 303 EnvMod。SMK37 OPEN 保留自己的音色体系，不提供 GM 128 音色表。
              

              同步与走带
              

              Clock、Start、Continue、Stop、歌曲位置和 MMC 不带 MIDI 通道，控制整机。选择 MIDI 时钟后，外部 Clock 按每四分音符 24 个脉冲同步；仅发送 Clock 不会自行播放。Start 从起点开始，Continue 从当前位置继续，Stop 停止播放并释放音序和琶音音符。
              歌曲位置 SPP（F2）在 MIDI 时钟模式下定位，每单位为一个十六分音符，各轨按自身循环长度取余；随后发送 Continue 与 Clock。Start 会重新回到起点。System Reset（FF）停止、回起点并释放全部音符。
              MMC 支持 Stop（01）、Play（02）、Deferred Play（03）、Record Strobe（06）、Record Exit（07）和 Pause（09）；接收设备 ID 00 或广播 7F。Play／Deferred Play／Record Strobe 从当前位置继续，Record Exit 不起作用（本版本没有录音），Stop／Pause 停止。在 MIDI 时钟模式仍需外部 Clock。
              例：F0 7F 7F 06 01 F7 为 MMC Stop；F0 7F 7F 06 02 F7 为 MMC Play。数字均为十六进制。
              同时连接多台 MIDI 设备时只让一台发送时钟和走带，避免重复脉冲。MTC 时间码、MMC 时间码定位／快进／倒带、RPN／NRPN、复音触后、GM Reset、Bank Select、Active Sensing 超时监控及未列出的控制器目前不实现，收到后忽略。
              

              蓝牙设置
              机身的蓝牙页已随 Classic Tabby Task 06 移除（为独立轨道启动腾出闪存）。蓝牙设置在网页工作台“项目与音色 → 蓝牙设置”：连接项目库后可打开或关闭蓝牙和蓝牙音频，选择 BLE MIDI 的 DEVICE／HOST 角色，并清除 MIDI 配对；改动立即写入设备并保存。蓝牙打开时 MIDI 服务自动可用；出厂默认蓝牙和音频打开、DEVICE 角色。时钟来源在 SYNC / MIDI 页（按 SEQ）选择。HOST 模式的设备扫描与连接列表不再提供。
              

              INT 与 MIDI 时钟
              INT：SMK37 OPEN 使用内部速度，K4 可设 30–300 BPM。MIDI：跟随外部 MIDI Clock，需外部发送 Start／Continue 才开始或继续。此时旋转速度不会改变外部速度。超过约两秒收不到时钟，屏幕显示 LOST；检查外部设备是否发送时钟，或切回 INT。

              21 · 常见问题
              

              没有声音，或 K8 看起来没有变化
              网页检查静音按钮、输出电平和系统音量。实机检查 K8、轨道 LEVEL、静音／独奏和输出连接；K8 最小位置静音。
              

              PLAY 按了不走
              按 SEQ 打开 SYNC / MIDI 页，检查 K1 CLOCK 是 INT 还是 MIDI；没有外部时钟时切回 INT。若播放走动但没声音，确认当前轨未静音且音量不为零。
              

              旋钮功能与预期不同
              先看当前页面和屏幕底部名称。K7 在总览切整套预设，在 EDIT 选单轨音色或鼓声部，在 SEQ 选步；K1–K4 随底部参数页改变。
              

              改好后重启丢了，或网页与实机不一致
              工作区编辑需要保存到 USER 槽。网页面板的左侧按键组第 4 键（SHIFT、FADER BANK、HOME 之后）只保存浏览器本地内容；顶部“保存到设备”完成后，设备槽位才有该项目。
              

              挂音、组合键没松开
              实机按 HOME＋PLAY。网页按 Esc 或“紧急停音”，并取消锁定按钮。停止演奏后再关闭其他 MIDI 输入来源。
              

              网页无法连接或按钮不可用
              已识别设备时，切换强制烧录会自动重新连接，不会自动写入。等待连接完成，勾选备份确认，再点击强制烧录并确认兼容警告。尚未连接时，请先点击连接设备。
              用电脑 Chrome／Edge 打开网页链接或完整 HTML，避免使用不运行脚本的附件预览。检查 MIDI／SysEx 权限、USB 数据线和设备连接；关闭占用端口的软件。若浏览器提示安全上下文问题，请从 localhost 或 HTTPS 打开页面。
              

              首次用播放按钮、面板 PLAY 或空格播放时，会先开启声音。开启失败会保持停止，处理浏览器声音提示后可再次播放。声音开启过程中点“紧急停音”或切换面板页，会取消等待中的播放。
              Tap Tempo：在 FX 的 DELAY 页直接连按 SEQ，其他页面按住 HOME 连按 SEQ，或点击网页 TAP；连续两拍起生效，最多平均四个间隔，范围 30–300 BPM。FX 用 K7 翻到 DELAY：K1 开关 SYNC，K2 调分频或毫秒，K3 调内部 BPM，K4 调反馈。新建工程默认同步八分音符；关闭 SYNC 后为固定时间 FREE，约 30–2040 毫秒。切换模式选择最接近的时间。T 为三连音，D 为附点；同步延迟跟随内部或外部 MIDI BPM，时钟丢失时保持最后间隔。旧工程保留原来的手动延迟；使用同步分频或扩展固定时间的工程需要新版固件。

libc/string/wcwidth.c

/*
 * This is an implementation of wcwidth() (defined in
 * IEEE Std 1002.1-2001) for Unicode.
 *
 * http://www.opengroup.org/onlinepubs/007904975/functions/wcwidth.html
 *
 * In fixed-width output devices, Latin characters all occupy a single
 * "cell" position of equal width, whereas ideographic CJK characters
 * occupy two such cells. Interoperability between terminal-line
 * applications and (teletype-style) character terminals using the
 * UTF-8 encoding requires agreement on which character should advance
 * the cursor by how many cell positions. No established formal
 * standards exist at present on which Unicode character shall occupy
 * how many cell positions on character terminals. These routines are
 * a first attempt of defining such behavior based on simple rules
 * applied to data provided by the Unicode Consortium.
 *
 * For some graphical characters, the Unicode standard explicitly
 * defines a character-cell width via the definition of the East Asian
 * FullWidth (F), Wide (W), Half-width (H), and Narrow (Na) classes.
 * In all these cases, there is no ambiguity about which width a
 * terminal shall use. For characters in the East Asian Ambiguous (A)
 * class, the width choice depends purely on a preference of backward
 * compatibility with either historic CJK or Western practice.
 * Choosing single-width for these characters is easy to justify as
 * the appropriate long-term solution, as the CJK practice of
 * displaying these characters as double-width comes from historic
 * implementation simplicity (8-bit encoded characters were displayed
 * single-width and 16-bit ones double-width, even for Greek,
 * Cyrillic, etc.) and not any typographic considerations.
 *
 * Much less clear is the choice of width for the Not East Asian
 * (Neutral) class. Existing practice does not dictate a width for any
 * of these characters. It would nevertheless make sense
 * typographically to allocate two character cells to characters such
 * as for instance EM SPACE or VOLUME INTEGRAL, which cannot be
 * represented adequately with a single-width glyph. The following
 * routines at present merely assign a single-cell width to all
 * neutral characters, in the interest of simplicity. This is not
 * entirely satisfactory and should be reconsidered before
 * establishing a formal standard in this area. At the moment, the
 * decision which Not East Asian (Neutral) characters should be
 * represented by double-width glyphs cannot yet be answered by
 * applying a simple rule from the Unicode database content. Setting
 * up a proper standard for the behavior of UTF-8 character terminals
 * will require a careful analysis not only of each Unicode character,
 * but also of each presentation form, something the author of these
 * routines has avoided to do so far.
 *
 * http://www.unicode.org/unicode/reports/tr11/
 *
 * Markus Kuhn -- 2007-05-26 (Unicode 5.0)
 *
 * Permission to use, copy, modify, and distribute this software
 * for any purpose and without fee is hereby granted. The author
 * disclaims all warranties with regard to this software.
 *
 * Latest version: http://www.cl.cam.ac.uk/~mgk25/ucs/wcwidth.c
 */
